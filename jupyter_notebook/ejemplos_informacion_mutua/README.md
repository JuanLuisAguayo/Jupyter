# 📊 Ejemplos de Información Mutua en Python

Este repositorio contiene ejemplos educativos y reproducibles para calcular **Información Mutua (Mutual Information)** en Python usando distintos métodos:

- Cálculo manual desde la definición.
- Histogramas 2D.
- `scikit-learn` (método estándar).
- KDE (Kernel Density Estimation).
